# Third-party materials and data boundaries

The repository code license applies to original code/documentation only to the extent contributors own the rights. It does **not** relicense source reporting, images, trademarks, court documents, participant materials or other third-party content. Source links and excerpts retain their original rights/restrictions.

The intended shareable package contains code, documentation, tests and explicitly synthetic examples. Full research corpus, raw captures, historical bundles and the Colab notebook embedding the corpus are **excluded from the publishable package**. Local access, a named-account share or a Git ignore rule does not establish redistribution permission.

| Material | Attribution and treatment |
| --- | --- |
| Committee to Protect Journalists reporting | Titles, URLs and dates are in the local research source register (not included in this synthetic submission package). The register records a CC BY-NC-ND 4.0 text notice except where otherwise noted, excluding images. This is not blanket permission to relicense articles or derived bundles under the code license. Check the applicable notice before distribution. |

| Other public reports and judicial material | Individual access/attribution limits apply. A URL or public court document does not mean all content is covered by the repository license. |

Preserve both, title, source URL and processing changes. The noncommercial local captures and populated records are excluded from this package and are not relicensed under MIT. See [import notes](docs/JUDGMENT_IMPORT.md). |
| TrialWatch packet, slides and local transcript | Preparation references excluded from the shareable package; no redistribution license asserted. Public organizer/orientation links may be cited. |
| Python | Intended review application uses the standard library; package does not redistribute a Python runtime. Inventory licenses if dependencies or bundled components are added. |
| Synthetic examples | Fictional test/demo records; keep labels and never present them as real cases or measured evaluation. |

Actual-case exports should retain publisher, title, canonical URL, dates, exact excerpt, attribution and unresolved limits. Include only what is needed for the stated purpose and check rights before distribution. Submissions should not include confidential, proprietary or sensitive personal data (packet p14, §13).

The TrialWatch name identifies the intended hackathon use, not deployment, endorsement, organizer approval of prework or verified adoption.

Preparation includes AI-assisted research/coding and stored extraction suggestions. Earlier frozen records document that work. Saved AI output is not human approval or authenticated source truth. The source register records provenance/access limits rather than certifying publisher claims.
