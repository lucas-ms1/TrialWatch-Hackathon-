# Demo previews

After cloning or downloading the repository, open either HTML file directly in a modern browser. No Python server, account, API key or internet connection is required for these previews.

- [Signals and advocacy strategy concept](signals-and-strategy.html): the intended connected workflow, from candidate case clusters through public response evidence to strategy options. Every place, person-level history, organization, passage and source is fictional. Switch views, inspect the shared-source and repost explanations, change the objective and preview a draft. This is an interface concept with no backend, automatic discovery, monitoring, analogue dataset or forecast. Choices reset on reload and never become saved human reviews.
- [Campaign comparison fallback](fallback.html): the implemented manual application's synthetic comparison output, generated through its backend using scripted example reviews and coding. It demonstrates existing mechanics, not human validation or advocacy effectiveness.

GitHub's file view displays HTML source; download the repository or clone it to view these pages in a browser. Follow the [main README](../../README.md) to run the working application with persistent local state. Each teammate's app data remains on their own computer.
