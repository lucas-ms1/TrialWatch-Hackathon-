Use synthetic default state or a fresh `--state-dir`; synthetic reviewer names are demonstration state only. Open `/rights.html`. Never present fictional records as cases or scripted checks as human validation. The public legal standards are real; synthetic evidence is invented.

| Minute | Action | Point to explain |
| --- | --- | --- |
| 0–1 | Explain intended user/task | Track 3 advocacy prioritization/comparison; overlap with Track 2; original provisional index |
| 1–3 | Intake a supplied source/excerpt or structured synthetic example | Concrete evidence route; source wording/attribution/date/locator; no URL fetch, binary PDF parsing or fresh AI inference |
| 3–6 | Open a profile; map support and contrary observations to notice or expression dimension, choose rule and save | Exact standard, fact-to-standard explanation, anchored concern; confidence/completeness separately; unknown remains unscored |
| 6–8 | Enter reviewer name, select exact dimensions, record reason, approve | Approval scope is visible; it does not authenticate all observations or original court records |
| 8–10 | Filter index; inspect related cases/context | Separate fair-trial/expression profiles, coverage/review/stale; similarities with differences; corpus-only frequency |
| 10–12 | Export Markdown/JSON; reopen saved state | Scores, excerpts, standards, gaps, versions and review scope travel together |
| 12–13 | Correct a passage with reason; reopen saved assessment | Original retained; previous assessment flagged stale; fresh revision requires review |
| 13–15 | Explain limits/next work and answer questions | No calibrated probability/composite, independent legal validation, real-time monitoring or advocacy impact result |
