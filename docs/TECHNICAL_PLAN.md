# Implementation: connected rights and intervention desk

October 10, 2026. Python standard-library HTTP/SQLite and a buildless frontend remain the stack. The [pending draft integration](AI_DRAFTING.md) adds saved raw model artifacts, citations/bridges, immutable revisions and an optional bounded authenticated local CLI route; no new dependencies, API-key setup or purchase. Default manual/synthetic operation remains provider-free. [Actual verification](VERIFICATION.md) distinguishes saved outputs, mocked tests and integrated request results. The [rights-only checkpoint](history/TECHNICAL_PLAN.before-connected-intervention-2026-10-09.md) and legacy comparison architecture remain preserved.

ReviewStore supplies intake, immutable seed records, duplicate/source links, evidence corrections and exact reviews. RightsService adds append-only assessments, original rubric registries and scoped rights reviews. InterventionService adds append-only dated contexts, options/proposals, human dispositions and outcome follow-up in the same local database. Historical comparison remains at `/index.html`; the connected interface is `/rights.html`. Loopback service is not a secure multi-user evidence platform.

The default seed is `reviewdesk/rights.synthetic.v2.json`; new state is `data/processed/connecteddesk-v2`. Original v1 fixtures/state remain distinct. Rubric v1 retains its nine definitions; v2 has thirteen core fair-trial, three conditional and four expression dimensions. Old profiles export their own rubric. New/split/changed dimensions start not assessed; old combined counsel/preparation scores are never distributed. No umbrella score, composite or probability.

Intake/context accept supplied UTF-8 text or structured JSON. Excerpts must occur in their own supplied source text. This validates presence/references, not authenticity, legal support or freshness. Publication, retrieval, event/relevant date and evidence cutoff remain distinct. A pre-cutoff source may report a later planned date. No URL fetching, binary PDF/OCR or model calls are integrated. Source text is data, never instructions.

Context propositions retain locator, date/unknown-date note, attribution, uncertainty and freshness. Optional clusters require exact reviewed membership and explicit time/place/issue links; shared geography does not establish coordinated action. Comparable episodes distinguish documented action, observed outcome/period, contribution and sequence.

A proposal requires at least two options including deferral and exact context/assessment/evidence dependencies. Routes, beneficiary/objective, authority, opportunity, timing, capacity, prerequisites, harms/preferences, contrary evidence, next step and reconsideration trigger are explicit. Deterministic rules explain six dispositions; party labels, deadlines, report counts and concern cannot substitute for issue-specific opportunity. Read [API](INTERVENTION_API.md) and [method](INTERVENTION_METHOD.md) for exact fields/rules.

Proposals snapshot all linked rights definitions/evidence/reviews, dated context, options and sources. Human review covers selected dimensions plus contextual references across all options/comparables/membership. Accept/revise/reject/defer records exact scope/reason. Revise saves a separately attributed disposition/note against the immutable proposal; changed options require a new proposal. Pending judgments remain visible; no whole-case approval gate blocks useful verification.

Evidence corrections, reassessment, changed review dependencies and context revisions stale saved proposals without overwriting earlier decisions. Fresh acceptance/revision of stale proposals is blocked; historical reject/defer remains available. Reopening/export recalculates staleness. Plans live in options/next steps. Follow-up kinds are observed action, observed outcome, conditional scenario and unknown outcome; observed claims require source excerpts. No probability or causal effect is inferred.

Use [README](../README.md) commands. `scripts/rehearse_intervention.py` creates fresh isolated synthetic state/exports including insufficient basis, specified deferral and correction/staleness. Tests verify missingness/versioning, contrary evidence, citations, exact review, concurrency, dependency changes and persistence. Actual checks/limits are in [VERIFICATION](VERIFICATION.md). Real research and original Lucas S review cannot approve new judgments.
